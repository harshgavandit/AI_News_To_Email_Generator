Use Informa in your AI assistant

Search public tech reporting, read the latest headlines, and ask for answers with links to original sources. The connector uses Streamable HTTP and is read-only. No API key is required.

Claude

  1. Open Customize → Connectors and choose to add a custom connector.
  2. Set the name to Informa AI, paste the connector URL, and choose Add.
  3. Enable the connector in your chat. If your organization manages connectors, ask your workspace owner to add it.

ChatGPT

  1. On ChatGPT web, open Plugins, click +, and choose Add custom MCP server. If your workspace uses the older Apps settings, choose Apps → Create.
  2. Name it Informa AI, paste the connector URL under Connection, and select No authentication.
  3. Review the connection prompt and create the plugin. Start a chat and type @Informa AI to select it. Your plan and workspace permissions determine whether you can add it.

Cursor

Add this entry to .cursor/mcp.json. Merge it into the existing mcpServers object if you already have one.

{
  "mcpServers": {
    "informa-ai": {
      "url": "https://getinformdaily.com/mcp"
    }
  }
}

OpenCode

In OpenCode 2, run these commands from the project where you want to use Informa. The second command shows whether the server is connected.

opencode mcp add informa-ai --url https://getinformdaily.com/mcp
opencode mcp list
OpenCode’s MCP guide ↗
Setup for OpenCode 1

Add this configuration to your project’s opencode.json. If it already has an mcp object, merge the informa-ai entry into it. Reopen OpenCode and run opencode mcp list to check the connection.

{
  "mcp": {
    "informa-ai": {
      "type": "remote",
      "url": "https://getinformdaily.com/mcp"
    }
  }
}

Google Antigravity

  1. In the agent panel, open ⋯ → MCP Servers → Manage MCP Servers → View raw config.
  2. Add the configuration below to mcp_config.json. If you already have an mcpServers object, merge the informa-ai entry into it.
  3. Save and return to MCP Servers to check for informa-ai.
{
  "mcpServers": {
    "informa-ai": {
      "serverUrl": "https://getinformdaily.com/mcp"
    }
  }
}
